# Support

## Start here

- Installation and privacy choices: [README.md](README.md)
- Planned work: [ROADMAP.md](ROADMAP.md)
- Security reports: [SECURITY.md](SECURITY.md)

For a reproducible bug, open a bug report and include the platform, app version,
transcription provider and exact error text. Never attach real recordings,
transcripts, API keys or the contents of your config file.

General setup questions can use GitHub Discussions after it is enabled. Feature
ideas should use the feature-request template so the privacy and platform impact
are visible before implementation starts.
