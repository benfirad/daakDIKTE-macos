# GitHub Sponsors profile draft

This is maintainer-facing copy for the GitHub Sponsors application. Update any
personal or financial details in GitHub directly; never commit them here.

## Short bio

I maintain daakDİKTE, an open-source, offline-first voice typing app for macOS
and Linux. It turns speech into text inside any app using local Whisper, with
optional Codex CLI and hosted-model workflows.

## About the work

daakDİKTE makes fast, private dictation accessible without requiring a
subscription. Sponsorship helps cover Apple signing and notarization, test
hardware, release engineering, accessibility work, translations and the time
needed to review community contributions.

The project is GPL-3.0 and its core local workflow will remain free software.
Funding priorities and project expenses are reported in public release notes.

## Suggested tiers

### Supporter — $3 monthly

Help pay for signing, hosting and release infrastructure. Optional name in the
supporter list.

### Builder — $10 monthly

Everything in Supporter, plus an optional profile link and access to public
roadmap voting. Votes inform priorities but do not override security,
accessibility or maintainer judgment.

### Sustainer — $25 monthly

Everything in Builder, plus an optional logo in the sponsor section and a
quarterly public group roadmap call when there is enough interest.

### One-time sponsor

Use one-time tiers for people who want to fund a release without a recurring
commitment. Do not promise delivery of a private feature as a sponsorship perk.
