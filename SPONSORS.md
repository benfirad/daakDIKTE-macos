# Sponsoring daakDİKTE

daakDİKTE is free software. Core dictation, local transcription and privacy
features will not be placed behind a paid tier.

Sponsorship pays for the unglamorous work that makes an open-source desktop app
dependable:

- Apple Developer membership, code signing and notarization
- release testing across Apple Silicon, Intel macOS and Linux desktops
- accessibility, language and first-run experience improvements
- privacy and dependency audits
- documentation, packaging and contributor support

## Funding principles

- Sponsorship never buys access to user recordings, transcripts or analytics.
- Security and data-loss fixes take priority over sponsored feature requests.
- Sponsors can suggest and discuss work, but cannot privately control the
  roadmap or the license.
- Recognition is optional. Anonymous sponsors are equally welcome.
- Material project expenses and sponsored milestones will be summarized in
  public release notes.

## Status

The repository funding configuration is ready. The maintainer's GitHub
Sponsors profile still needs GitHub's identity, tax and payout review before
the button can accept payments. Until that review is complete, starring the
repository, reporting reproducible bugs and improving a translation are the
best ways to support the project.

Maintainer setup copy and suggested tiers live in
[docs/github-sponsors-profile.md](docs/github-sponsors-profile.md).
